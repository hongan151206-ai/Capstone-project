# IBM Data Science Capstone - SpaceX Falcon 9 landing prediction

Run everything (needs Internet): `pip install -r requirements.txt && python run_all.py`
This produces the CSVs, charts, `spacex_map.html` and `Data_Science_Capstone_Project_Report.pdf`.
Run the dashboard separately: `python 07_dash_app.py`.

| Step | File |
|---|---|
| Data collection (API) | 01_spacex_api_collection.py |
| Data collection (web scraping) | 02_web_scraping.py |
| Data wrangling | 03_data_wrangling.py |
| EDA with SQL | 04_eda_sql.py |
| EDA with visualization | 05_eda_visualization.py |
| Folium map | 06_folium_map.py |
| Plotly Dash app / static figures | 07_dash_app.py / 07b_dash_figures.py |
| Predictive analysis | 08_predictive_analysis.py |
| Slides PDF | build_report.py |
